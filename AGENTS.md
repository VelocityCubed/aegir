# Speaker-design knowledge

For loudspeaker research, recommendations, modelling, or interpretation, start at
`docs/speaker-design/README.md`. Read its task-specific pointers before loading the
whole wiki. Keep source facts, derivations, assumptions, simulations, and physical
measurements distinct. Never present the current bass study as a validated complete
loudspeaker, or synthetic example data as manufacturer specifications.

Preserve existing ÆGIR projects before changing the live workspace. The wiki's
model records and exports are project data; they do not require application changes.
